# Changelog

## 0.1.0

- Initial release: `planning-engineering-work` skill — a conversational
  Agile-Coach / Scrum-Master facilitator that brainstorms work items, refines
  them into create-issue-format GitHub issues with epic/sub-issue decomposition,
  gates on explicit consensus, creates the issues via `gh`, and optionally tracks
  them as a GitHub Projects (v2) iteration.
